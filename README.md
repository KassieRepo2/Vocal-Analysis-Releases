# Vocal Analysis (Release Page)

**Vocal Analysis** is a **JavaFX + Python** desktop application that analyzes voice recordings and visualizes **pitch & resonance insights** to help track progress over time.

**Tech:** Java, JavaFX, Python, SQLite, pandas, NumPy, Matplotlib, scikit-learn  
**Source:** Currently private. This repository hosts public releases, screenshots, and documentation.

**Download:** Get the latest installer from [**Releases**](https://github.com/KassieRepo2/Vocal-Analysis-Releases/releases).

**Privacy:** Audio is processed locally; nothing is uploaded.

---

## Installation (Windows)
1. Install **Python 3.13** from the Microsoft Store.  
2. Install the application from the latest release.
3. Launch the app and follow the on-screen prompts.

Need help? Email: **VocalAnalysisDev@gmail.com**

---

## What it does
Vocal Analysis is designed to give clear, actionable feedback so you can:
- Track your progress over time
- Understand how your voice is changing
- Feel more confident and less overwhelmed during training

## Key features
- Record audio or import an existing file
- Analyze pitch trends and resonance/formant-related insights
- Visualize results with charts and summaries
- Save and review results over time (SQLite)

## How it works (high-level)
JavaFX UI → Python analysis pipeline → SQLite persistence → Matplotlib charts & summaries
